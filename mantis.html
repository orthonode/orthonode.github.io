Entry Logic

Precision Entry Rules.

No guessing. Every trade passes a deterministic checklist. MANTIS stays in cash when conditions aren't perfect — idle hours are not wasted hours.

standard_entry.rs
// All conditions must be true
is_flash_market == false
consensus_score >= 68
hours_to_resolve <= 24.0
market_volume >= $1,000
yes_price between 0.05 and 0.55
total_exposure + bet <= $40.00
today_pnl > -$15.00

// Kelly-capped bet size
bet_usd = kelly(score, category_mult)
max_bet = $10.00 // hard cap
kelly.rs — category multipliers
// Fraction of capital per trade
max_fraction = 0.15
min_bet = $1.00

// Category confidence multipliers
Standard × 0.90
Geopolitical × 1.00 // 0% fee
Political × 0.70
Sports × 0.80 // no live scores

// Exit strategy
profit_lock = 40% // trailing stop
losing_exit = 20% // cut losses
rescore_interval = 300s
Capital Protection

8 Hard Risk Rules.

Every order passes through risk::check() before any execution. A single violation kills the order. No workarounds. No exceptions.

01
Exposure Cap
Total open positions must not exceed $40 including the new bet. Any order that would breach this is rejected.
Hard cap: $40.00
02
Bet Size Cap
Standard bets truncated to $10 max. Oversize is silently corrected before placement — never rejected, never crashes.
Max: $10 standard
03
Daily Loss Limit
If today's realised P&L drops below -$15, ALL orders halt for the rest of the UTC day. Logged as DAILY_LOSS_LIMIT_HIT.
Limit: -$15.00 / day
04
Liquidity Filter
Standard markets must show >$1,000 total volume. Thin markets have wide spreads and poor price discovery — not worth the risk.
Min volume: $1,000
05
Minimum Edge
Consensus score must clear the conviction threshold. Below this threshold the signal is uncertain — MANTIS stays in cash.
Minimum conviction threshold
06
No Duplicate Positions
One position per condition_id. Never average down. Never add to a winner. A matching open position returns RiskError::DuplicatePosition.
1 position per market
07
Price Zone Filter
YES price must be 0.05–0.55. Markets priced outside this range carry excessive house edge or are near-resolved with negligible reward.
Zone: $0.05 – $0.55
08
Geoblock Guard
On startup MANTIS performs a connectivity check. If the deployment server is blocked from the exchange: immediate hard stop. No silent failures, no partial operation.
Fail-closed · exit(1)
