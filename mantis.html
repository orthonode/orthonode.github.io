    Capital Protection

    8 Hard Risk Rules.

    Every order passes through risk::check() before any execution. A single violation kills the order. No workarounds. No exceptions.

    01
    Exposure Cap
    Total open positions must not exceed $40 including the new bet. Any order that would breach this is rejected.
    Hard cap: $40.00
    02
    Bet Size Cap
    Standard bets truncated to $10 max. Oversize is silently corrected before placement — never rejected, never crashes.
    Max: $10 standard
    03
    Daily Loss Limit
    If today's realised P&L drops below -$15, ALL orders halt for the rest of the UTC day. Logged as DAILY_LOSS_LIMIT_HIT.
    Limit: -$15.00 / day
    04
    Liquidity Filter
    Standard markets must show >$1,000 total volume. Thin markets have wide spreads and poor price discovery — not worth the risk.
    Min volume: $1,000
    05
    Minimum Edge
    Consensus score must clear the conviction threshold. Below this threshold the signal is uncertain — MANTIS stays in cash.
    Minimum conviction threshold
    06
    No Duplicate Positions
    One position per condition_id. Never average down. Never add to a winner. A matching open position returns RiskError::DuplicatePosition.
    1 position per market
    07
    Direction Consensus
    If Groq and Claude disagree on the direction of the trade, the order is rejected entirely. Both models must agree — no split-signal trades reach execution.
    Reject — no consensus
    08
    Maker Position Cap
    Maker orders are hard-capped at $5 per side. Any maker order exceeding this is silently truncated before placement — never rejected, never crashes the engine.
    Max: $5 per side
